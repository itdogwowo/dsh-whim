# dsh-whim · 念頭

**一次性的臨時調查。** 側欄多一個入口，丟一句話進去，它自己開一個獨立對話把答案查回來——查完留下一頁結論，不碰你正在進行的工作。

![念頭](icon.svg)

## 這是什麼

你正在寫東西，突然想到一個跟手上工作無關的問題（「這個 API 到底回什麼」、「那個函式庫怎麼用」、「這張圖的授權是什麼」）。開一個新對話去查，會把注意力扯走；不查，念頭就掉了。

念頭把它變成一件一次的事：**一個念頭 = 一個獨立 session**。它自己開一個對話、自己查、自己寫結論，主工作完全不受影響。

## 工作模式：一個資料夾，每個問題一條新對話

念頭只用**一個資料夾**（你自己選的那個），不跨工作區、不掃全 Machine：

1. 那個資料夾同時註冊成 DSH 的 **workspace**，所以每個念頭的對話都會出現在 DSH 自己的側欄
2. 每個問題 → 開一條**新的** DSH 對話，掛在那個 workspace 底下
3. 這一輪**留在插件裡跑完**，答案直接顯示在面板上；想接著問，按「開啟對話」再去 DSH 原生介面——工具輸出、權限詢問、中斷、子代理全部照常
4. 插件面板負責的是「這一輪的紀錄」：每個念頭一個 `w-日期-亂數/` 資料夾，裝 meta、問答紀錄與一頁結論

## 安裝

在 DSH 的 **Plugins** 頁面按 **Add plugin**，指向這個資料夾（本機目錄安裝）。

安裝後側欄會多一個「念頭」入口，點下去就是主頁面。

## 第一次使用：選一個資料夾

念頭不放進 DSH 自己的資料夾，而是放進你選的地方。第一次點開「念頭」時，頁面會問一次：

- 輸入框預填 `~/whims`（`~` 展開成你的家目錄）；也可以按旁邊的「瀏覽…」用 DSH 原生的資料夾選擇器挑
- 如果那個預設位置已經有念頭資料，下面會多一句提示——選它就會直接接上
- 按「開始」之後，選擇會記在 `~/.dsh/whim/config.json`，之後不再問

想換位置：主頁面右上角的「換位置」。**舊資料不會被搬移**，只是接下來讀寫改到新地方。

`DSH_WHIM_ROOT` 環境變數的優先序最高；設了它，面板上的選擇會被覆寫（設定畫面會直接告訴你這件事）。

## 用法

1. 側欄點「念頭」→ 主頁面
2. 輸入框寫下你的問題 → Enter
3. 它開一條**新的** DSH 對話（掛在你選的資料夾底下），這一輪在面板裡跑完、答案直接顯示
4. 想接著追問、看工具輸出、批准權限，按「開啟對話」切到那條 DSH 原生對話
5. 回到「念頭」面板，左邊清單點一筆，右邊看結論；「過程」可以展開看它怎麼查的
6. 查完的念頭可以丟掉（只刪那一個資料夾，**不會刪掉 session**——那是你的對話紀錄）

## 檔案在哪

```
~/.dsh/whim/config.json                ← 你選的資料夾（第一次使用時寫入）

~/whims/                               ← 預設位置（也可以是你選的任何資料夾）
  index.json                           ← 清單（含 status、sessionId）
  w-20261116-ab12/                     ← 一個念頭一個資料夾
    meta.json                          ← 狀態、sessionId、輪數
    log.md                             ← 每輪的問答紀錄
    findings.md                        ← 結論
    （其他成品檔）                      ← 這一題產出的文件、表格、程式…
```

這一題如果有成品，agent 只會寫在它自己的 `w-…/` 資料夾裡，不會碰你的專案或其他念頭。

`DSH_WHIM_ROOT` 可以直接指定位置，蓋過上面兩者。

## 怎麼做的

- **宿主半**（`lib/index.js`）：掛一條 `/api/dsh-whim/rpc` 路由，只管資料夾與設定檔讀寫
  - 硬規則：**不建立、不刪除、不讀寫任何 DSH session**。session 的生命週期屬於 DSH
- **瀏覽器半**（`lib/client.js`）：側欄入口 + `main` 頁面
- **workspace**：使用者選的資料夾用 `workspaces.create({ path })` 註冊成 DSH workspace（幂等）
- **session**：用 `remote.session.create()` 開、`follow()` 收串流、`prompt()` 送訊息；這一輪在插件裡跑完，使用者按「開啟對話」才 `uiWorkspace.openSession()` 切到原生對話
- **不碰你正在用的對話**：念頭一律開新 session，不塞進任何既有對話

## 開發

```bash
node --check lib/index.js && node --check lib/client.js
node test/host-smoke.mjs
node test/client-smoke.mjs
```

沒有 build step：`lib/client.js` 是 `window.__ModuleLoader__.load({...})` 的原始碼，DSH 直接載入。

兩支煙霧測試都跑在暫存資料夾裡，跑完就刪，不碰真的資料。
